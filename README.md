# Superstore_Sales-Excel_Project
# 1. Project Overview

This project analyses the Superstore sales dataset using Microsoft Excel. The work combines an end-to-end Excel practical assignment with an interactive executive dashboard. It focuses on preparing and analysing order-level data, summarising sales and profit performance, and presenting business findings in a format that is easy to explore.

The dashboard includes Year, Region, Category and Sub-Category filters, KPI cards, trend charts, category and regional comparisons, and detailed performance tables.

# 2. Project Requirements
• Analyse sales and profit trends.

• Compare regional and category performance.

• Identify profitable and loss-making products.

• Create an interactive executive dashboard.

# 3. Tools & Technologies
Microsoft Excel, Pivot Tables, Pivot Charts, Excel formulas, Conditional Formatting, Slicers, Sorting and Filtering.

Functions: SUM, IF, COUNTIF, SUMIFS, VLOOKUP, IFERROR, TRIM, YEAR and MONTH.

# 4. Challenges Faced
• Handling missing and duplicate records.

• Applying complex Excel formulas.

• Organising Pivot Tables.

• Identifying loss-making products.

• Designing a clear and interactive dashboard.

# 5. Key Business Insights
• Technology generated the highest category profit (about $145.5K).

• West region recorded the highest profit (about $108.4K).

• 2017 had the highest yearly sales (about $733.2K).

• Tables generated a loss of about $17.7K.

• Bookcases and Supplies also reported losses.

# 6. Recommendations
• Review pricing and discounts for loss-making products.

• Focus on high-performing Technology products.

• Improve profitability in Central and South regions.

• Monitor profit margins regularly.

• Add monthly trends, forecasting and top/bottom product analysis.
